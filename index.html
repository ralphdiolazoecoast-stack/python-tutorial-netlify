1. Introduction to Python

Python is a high-level programming language that is simple, readable, and widely used for web development, automation, data analysis, artificial intelligence, and many other applications.

First Python Program

print("Hello, World!")

The print() function is used to display text or information on the screen.

Tip: Python uses indentation to organize blocks of code, making programs easier to read.

2. Variables

Variables are used to store information in a program. A variable can contain text, numbers, or other types of data. 

name = "Ralph"
age = 18

print(name)
print(age)

In this example, name stores text while age stores a number.

3. Conditional Statements

Conditional statements allow a program to make decisions based on a condition. 

age = 18

if age >= 18:
    print("You are an adult.")
else:
    print("You are a minor.")

The if statement checks whether a condition is true. If it is false, the else statement runs.

4. Loops

Loops are used when you want to repeat a block of code.

Example using a for loop:

for i in range(5):
    print(i)

This program prints the numbers from 0 to 4.
